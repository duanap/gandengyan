# 干瞪眼 V1.3 验收报告

2026-11-24，Windows 11，Go 1.27.4，Node 22.23.3，Chromium 159。

## 规则和联机

同一 Go 规则引擎判定真人、AI 与提示。覆盖物理牌所属、恰好大一级、单 2／对 2、顺子／连对长度、万能牌规范化、三至六炸、余牌和收尾。非法出牌保持状态和 revision。首位出完立即零和结算；连续 N−1 次不出后按模式补牌。牌堆耗尽后继续打，上局在座赢家首出。

房间支持 2–5 人、真人联机、AI 快速开局和混合席位。每房串行处理命令，快照按席位投影，双王提醒和摸到的牌面仅本人可见。测试覆盖会话绑定、过期、房主权限、版本、重复请求、非法牌 ID、Origin、限速、慢连接、房间隔离和回收。

## AI 公平性与对照赛

输入包括自己的手牌、公开的历史牌、对手余牌数和积分、牌堆数量及行动状态。优先合法收尾，对剩余手牌做有界拆分，并用未知牌的假设分布进行短程推演。改变真实对手手牌和牌堆顺序、保留同一可见视图，决策一致。取消和已过期的决策不能提交。

设置 `GDY_AI_TOURNAMENT=1` 后运行 `go test -C server -count=1 -v ./internal/ai -run '^TestPolicyTournament$'`。固定种子 23001–23320，轮换 AI 座位，与两种基线分别对阵每组 320 局，共 5,120 局。

## 并发回环压测

设置 `GDY_LOAD=1`，运行 `go test -C server -count=1 -v -parallel 64 ./internal/gateway -run '^TestLoopbackLoad$'`。Core Ultra X7 358H，16 线程，约 31.5 GiB RAM。48 房、96 条实际 WebSocket 连接，经典与极速各半，15.19 秒完成 2,880 个状态变更，约 190 动作/秒，错误 0。提交至双方收到新快照的 p50 0.548 ms、p95 1.847 ms、p99 3.933 ms、最大 8.684 ms。进程 Go 用户 CPU 8.17 秒，结束时 Go Alloc 7.43 MiB、Sys 31.89 MiB，均包含本机测试客户端。断开后所有房间均回收。
